# 단톡위키 LLM 프롬프트

이 폴더의 Markdown이 Gemini에 보내는 지시문의 원본이다. 코드 수정 없이 문장을 고쳐 결과를 조정할 수 있다.

## 구조

| 파일 | 역할 |
| --- | --- |
| `style.md` | 모든 문서에 공통으로 붙는 문체·사실성·표기 규칙 (system instruction) |
| `room/_document.md` | 단톡방 문서 전체에 대한 지시 |
| `room/<섹션 key>.md` | 단톡방 문서의 해당 섹션을 쓸 때의 지시 |
| `person/_document.md` | 인물 문서 전체에 대한 지시 |
| `person/<섹션 key>.md` | 인물 문서의 해당 섹션을 쓸 때의 지시 |

## 규칙

- **`.md` 파일이 있는 섹션만 LLM이 쓴다.** 파일을 지우면 그 섹션은 규칙 기반 문장으로 돌아가고, 섹션 key로 파일을 추가하면 LLM 대상이 된다.
- 단톡방 섹션 key는 `src/screens/home/utils/roomWiki/sections*.ts`의 `section(ctx, "<key>", ...)` 값이다. (`related`는 링크 목록이라 파일을 두지 않았다. 통계·어워즈·연감·유형 도감·분석 기준 섹션은 문서에서 뺐다.)
- 인물 섹션 key는 `overview`, `traits`, `nicknames`, `quotes`, `relationships`, `trivia`다.
- LLM은 각 하위 문단의 서술을 쓴다. LLM이 쓴 하위 문단에서는 서술이 통계 목록·표·막대를 대신하고(그 숫자는 "사실"로 이미 넘겼다), 인용 상자와 시간대 차트만 남는다. LLM이 쓰지 않은(실패하거나 빈 배열을 준) 하위 문단은 규칙 기반 문장과 목록이 그대로 남는다.
- LLM 출력에서 앱이 해석하는 표기는 `**굵게**`, `~~취소선~~`, `[[이름]]`, `[* 각주]`, `> 이름: 메시지`(대화 장면)뿐이다. 새 표기를 프롬프트에 추가하려면 `src/screens/home/utils/aiProse/applyProse.ts`도 함께 고쳐야 한다.
- 각주와 대화 장면 인용은 서버가 실제로 보낸 발췌와 대조해, 일치하지 않으면 지운다(`verifyQuotes.ts`).
- LLM에는 원본 전체가 아니라 연속된 대화 장면 20개 안팎과 구성원별 한 줄 발췌(합계 300줄 이하)만 보낸다. 전화번호·계좌번호·이메일·주민번호와 링크는 브라우저에서 미리 가린다(`sampleExcerpts.ts`).
- `_`로 시작하는 파일과 이 README는 섹션으로 취급하지 않는다.
- 파일은 서버가 처음 요청을 받을 때 읽고 메모리에 보관한다. 개발 서버에서는 수정 후 서버를 재시작하면 반영된다.
